# سهم — تطبيق الآيفون

غلاف أصلي (WKWebView) لمنصة سهم التي تعمل على جهاز المالك.

- **لا يحتوي أي سر.** يُربط مرة واحدة برمز من لوحة الإدارة، ويُحفظ الرمز في Keychain الآيفون.
- **عنوان المنصة يتغير مع كل تشغيل** (نفق Cloudflare السريع)، فيقرأ التطبيق مؤشرًا مشفّرًا (AES-256-GCM) من
  `huggingface.co/spaces/fdgwse5/sahm-app` لا يفتحه إلا رمز الربط.
- **البناء:** GitHub Actions (macOS) ينتج `Sahm.ipa` غير موقّع في Releases، ويشغّل التطبيق في محاكي الآيفون ويرفق صوره.

## التثبيت
أي IPA يحتاج توقيعًا قبل تثبيته — هذا شرط Apple لا يمكن تجاوزه:
1. **Sideloadly** (ويندوز) أو **AltStore**: بحساب Apple ID مجاني، صالح 7 أيام ثم يُعاد توقيعه.
2. حساب مطوّر Apple مدفوع (99$ سنويًا): سنة كاملة.

بعد التثبيت: لوحة الإدارة في سهم (ضغط مطوّل على «الرئيسية») ← «ربط تطبيق الآيفون».
